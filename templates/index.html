Ajuda

Tutorial completo e guia de uso

🚀 Início Rápido

  1. Configure a API - Pegue em my.telegram.org/apps
  2. Adicione Sessões - Importe seus arquivos .session
  3. Extraia Membros - Escolha um grupo e extraia a lista
  4. Adicione Membros - Configure e inicie o processo

1. Configuração

Primeiro, configure suas credenciais da API do Telegram:

  • Acesse https://my.telegram.org/apps
  • Faça login com seu número do Telegram
  • Crie um novo aplicativo
  • Copie o API ID e API Hash
  • Cole na aba Configuração e salve

2. Sessões

Gerencie suas contas do Telegram:

  • Importar em Massa: Selecione vários arquivos .session
  • Status das Sessões:
    • 🟢 Verde - Ativa e funcionando
    • 🟡 Amarelo - Em flood (aguarda 3 dias)
    • 🔴 Vermelho - Desconectada

3. Tarefas

Gerencie até 10 grupos simultaneamente:

  • Adicione grupos à fila com meta de membros
  • Configure limite diário (ex: 50 membros/dia)
  • Sistema reseta automaticamente a cada 25 horas
  • Processamento automático entre todos os grupos

⚠️ Avisos Importantes

  • Use delays maiores para evitar FLOOD
  • Não adicione mais de 50 membros por sessão por vez
  • Aguarde algumas horas entre processos
  • Faça backup das sessões regularmente
  • Respeite os limites do Telegram
